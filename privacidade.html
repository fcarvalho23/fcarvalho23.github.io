Política de Privacidade — Automação Interbrasil

Este aplicativo é usado apenas pelo próprio titular da conta Google que o autoriza, para automatizar rotinas internas.

  • Os dados do Google (Gmail, Drive, Planilhas, Documentos, Agenda, Contatos) são acessados somente para executar essas rotinas em nome do titular.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O token de acesso fica guardado em servidor privado do titular e pode ser revogado a qualquer momento em myaccount.google.com/permissions.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato: pelo e-mail de suporte exibido na tela de autorização do Google.
